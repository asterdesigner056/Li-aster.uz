# 01 · Контент: тексты, фото, модели, цены

Всё редактируется в `src/`. После правок:

- `npm run dev` — сайт открыт на http://localhost:3000 и **сам обновляется** при каждом сохранении;
- или `npm run build` — пересобрать `dist/` один раз.

> Если что-то указано неверно (нет перевода, не найдено фото), сборка напишет об этом в консоли строкой с ⚠.

## Где что менять

| Что | Где |
|---|---|
| Телефон, адрес, часы работы, ссылки на карты | `src/content/config.json` → `phone`, `dealers[0]` |
| Соцсети (Instagram, Telegram, YouTube) | `config.json` → `social` (пустая ссылка — иконка скрыта) |
| Title, description, keywords, Open Graph главной | `i18n/ru.json` и `uz.json` → `meta` (`title`, `description`, `keywords`, `ogTitle`, `ogDescription`) |
| Домен сайта | `config.json` → `siteUrl` (canonical, hreflang, sitemap, Open Graph) и `lead.website` (поле в CRM) |
| Заголовок первого экрана главной | `src/content/i18n/ru.json` и `uz.json` → `hero.title` (`<br>` — перенос строки) |
| Все общие тексты: меню, кнопки, формы, FAQ, блоки главной | `src/content/i18n/ru.json`, `uz.json` |
| Тексты модели, характеристики, SEO-заголовок | `src/content/models/<id>.json` |
| Порядок моделей на сайте | `config.json` → `modelOrder` |
| Цена модели | `models/<id>.json` → `"price": 1150000000` (нет поля или 0 — «Цена по запросу») |
| Метка «Новинка» на карточке | `models/<id>.json` → `"badge": { "ru": "Новинка", "uz": "Yangi" }` (удалите — метка пропадёт) |
| Прайс-лист PDF | положить в `src/price/`; для каждого языка свой файл — поле `priceList` модели: `{ "ru": "price/li-l8-ru.pdf", "uz": "price/li-l8-uz.pdf" }`. Нет файла — кнопка скрыта |
| Политика конфиденциальности | `i18n/*.json` → `privacy`; юр. название — `config.json` → `legalName` |
| Цвета, шрифты, отступы | `src/assets/css/style.css` → переменные в `:root` в начале файла |

Тексты на двух языках записываются парой: `{ "ru": "…", "uz": "…" }`.
Единицы в характеристиках пишутся по-русски (`5 050 мм`, `330 кВт / 449 л.с.`) — на узбекской версии они переводятся автоматически.

## Фото

```
src/assets/img/
├── home/
│   ├── hero.webp        первый экран главной           ~2560×1440
│   ├── interior.webp    блок «Салон»                   ~1800 по ширине
│   ├── offer.webp       блок «Персональное предложение» ~2400 по ширине
│   └── og.jpg           превью ссылки в Telegram/соцсетях 1200×(630–1350), JPEG
└── models/<id>/                (id: l6-ultra, l8-ultra, l8-livis, l9-ultra, l9-livis)
    ├── card.webp        карточка в «Модельном ряду» — машина сбоку на светлом/прозрачном фоне
    ├── hero.webp        первый экран страницы модели — широкий кадр, ≥ 2000 px
    ├── section-1…5      фото к 5 блокам-преимуществам (порядок = порядок блоков в models/<id>.json)
    └── gallery-1…N      галерея (любое количество)
```

### Как заменить фото — без правки кода

1. Положите файл **с тем же именем** в ту же папку. **Расширение не важно**: `hero.jpg`, `hero.png`, `hero.webp` — сборка найдёт сама.
   (Старый файл с другим расширением удалите, иначе возьмётся первый найденный — приоритет: webp, jpg, jpeg, png, avif.)
2. Сохраните — в режиме `npm run dev` страница обновится сама.

### Галерея — полностью автоматическая

Галерея модели = все файлы `gallery-1`, `gallery-2`, … в папке модели, по порядку номеров.
Добавили `gallery-7.jpg` — фото появилось; удалили — исчезло. JSON трогать не нужно.

### Размер и вес

- Ширина: hero — до 2560 px, блоки — до 1800 px, галерея — до 2000 px, карточка — до 1400 px.
- Вес: до ~300 КБ на фото (hero — до 800 КБ). После сборки консоль перечислит слишком тяжёлые фото.
- Формат: **WebP** (качество 75–80) — в 2–3 раза легче JPEG. Сжать можно на https://squoosh.app.

## Добавить модель

1. Скопируйте `src/content/models/l8-ultra.json` → `src/content/models/<новый-id>.json`.
2. Поменяйте `id`, `slug` (часть адреса: `/models/<slug>/`), `name`, тексты, характеристики, `priceList`.
3. Создайте папку `src/assets/img/models/<новый-id>/` с `card`, `hero`, `section-1…5`, `gallery-…`.
4. Добавьте `<новый-id>` в `config.json` → `modelOrder` (на нужное место).

Страница RU/UZ, карточка на главной и в «Других моделях», пункт в форме, ссылка в подвале, sitemap и SEO-разметка появятся сами.

**Удалить модель** — уберите её `id` из `modelOrder` (файл можно оставить).

**Сетка карточек подстраивается сама**: до 5 моделей — в один ряд; больше — ряды делятся поровну (6 → 3+3, 7 → 4+3, 8 → 4+4, 9 → 5+4), неполный ряд встаёт по центру. На планшете — по 2 в ряд, на телефоне — по одной друг под другом. Колонки считает сборка (`gridCols` в `scripts/build.js`).

## Структура файла модели (`src/content/models/<id>.json`)

| Поле | Что это |
|---|---|
| `id` | внутренний идентификатор = имя файла и папки с фото |
| `slug` | адрес страницы: `/models/<slug>/` |
| `name` | название (`Li L9 Ultra`) — также уходит в CRM как модель (без «Li») |
| `class`, `tagline`, `intro` | подзаголовок, слоган, вводный абзац (RU/UZ) |
| `seo.title`, `seo.description` | заголовок и описание для поисковиков (RU/UZ) |
| `badge` | метка на карточке (необязательно) |
| `card`, `hero` | пути к фото |
| `priceList` | PDF прайс-листа по языкам: `{ "ru": "price/….pdf", "uz": "price/….pdf" }` |
| `price` | цена в сумах (необязательно) |
| `key` | 4 цифры на первом экране: `{ "v": "571", "l": { "ru": "л.с.", "uz": "o.k." } }` |
| `sections` | 5 блоков-преимуществ: фото `img`, `eyebrow`, `title`, `text` |
| `specs` | таблица характеристик: группы (`dims`, `power`, `chassis`, `cabin`, `safety`) и строки `[ключ, значение]`; подписи ключей — в `i18n/*.json` → `model.spec` |

## Аналитика

`config.json` → `analytics`: впишите ID — счётчик подключится на всех страницах и автоматически разрешится в политике безопасности.

| Поле | Пример |
|---|---|
| `yandexMetrika` | `98765432` |
| `ga4` | `G-XXXXXXX` |
| `metaPixel` | `123456789012345` |
| `googleVerification`, `yandexVerification` | коды подтверждения из Search Console / Вебмастера |

Цели (события) уже размечены: `lead_submit` (заявка отправлена), `book_open`, `cta_more_<id>`, `cta_book_<id>`,
`cta_header`, `cta_hero_models`, `cta_hero_price`, `cta_model_hero`, `cta_offer`, `cta_mbar`, `price_download_<id>`,
`call_header` / `call_dealer` / `call_form` / `call_mbar`, `route_yandex` / `route_google`, `social_<сеть>`.
