# 05 · Безопасность

## PHP2Shell (CVE-2026-109618 / CVE-2026-109619)

Критические уязвимости в самом PHP (удалённое выполнение кода), исправлены 21.10.2026. Касаются любого PHP-сайта.

1. **Обновить PHP** на хостинге: 8.2.35 / 8.3.36 / 8.4.27 / 8.5.12 или новее. Ветки 8.1 и старше не обновляются.
2. Если сайт работал на старой версии после 17.10.2026 — проверить журналы сервера, сменить пароли панели/FTP/SSH и токен Telegram.
3. По возможности — WAF (например, Cloudflare): там есть правила против PHP2Shell.

`send.php` пишет предупреждение в журнал ошибок сервера, если версия PHP уязвима.

## Что защищено в коде

| Угроза | Защита |
|---|---|
| PHP2Shell через загрузку файлов (multipart, upload progress) | формы шлют `urlencoded`; `.htaccess` отклоняет multipart и тело > 8 КБ до запуска PHP; `.user.ini` отключает `session.upload_progress`, ограничивает `post_max_size` |
| Запуск посторонних PHP-файлов | `.htaccess` разрешает только `send.php`; `config.php`, `lead.php`, `secret.php` закрыты |
| Утечка заявок (персональные данные) | хранение вне публичной папки; запасной вариант — папка с неугадываемым именем + запрет доступа; на nginx — `deploy/nginx.conf` |
| Спам, флуд CRM | ловушка для ботов, проверка времени заполнения, лимиты по IP и общий; IP нельзя подделать заголовком |
| Заявки с чужих сайтов | проверка `Origin`/`Referer` |
| Подмена полей | белые списки модели/типа/языка, строгая проверка имени и телефона, отбрасывание массивов и управляющих символов |
| CSV-инъекция (формулы Excel) | экранирование значений, начинающихся с `= + - @` |
| XSS, внедрение скриптов | CSP заголовком сервера: только свои скрипты, без встроенных скриптов и `on*`-обработчиков; данные страницы — JSON-блок; Telegram-сообщения экранируются |
| Clickjacking, подмена MIME | `frame-ancestors 'none'`, `X-Frame-Options: DENY`, `nosniff`, HSTS, `Referrer-Policy`, `Permissions-Policy` |
| Раскрытие путей и ошибок | `display_errors` выключен, ошибки — только в журнал |
| Обход папки на dev-сервере | `scripts/dev.js` не отдаёт файлы вне `dist/` |

## Секреты

| Что | Где | В репозиторий |
|---|---|---|
| Токен Telegram, e-mail | `src/php/config.php` → лучше `../aster-li-config.php` на сервере | только пустой шаблон |
| `secret.php` | генерируется при первой сборке | нет (`.gitignore`) |
| Заявки (`leads.csv`, `crm.log`) | только на сервере | нет |

## Чек-лист

- [ ] Загружены `.htaccess` и `.user.ini`; на nginx применён `deploy/nginx.conf`.
- [ ] `https://домен/config.php` и `/send.php` (GET) — 403/404.
- [ ] Токены — в `aster-li-config.php` уровнем выше публичной папки.
- [ ] Доступ к хостингу по SFTP, двухфакторный вход в панель.
- [ ] Права: папки 755, файлы 644; никаких 777.
- [ ] Периодически удалять старые заявки из `leads.csv` (персональные данные).
