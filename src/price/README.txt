Прайс-листы PDF для кнопки «Скачать прайс-лист» на страницах моделей.
Для каждого языка свой файл: li-<модель>-ru.pdf и li-<модель>-uz.pdf.
Какой файл у какой модели — поле "priceList" в src/content/models/<модель>.json:
  "priceList": { "ru": "price/li-l8-ru.pdf", "uz": "price/li-l8-uz.pdf" }
Если файла нет — кнопка на странице не показывается.
Обновить прайс: положите новый PDF с тем же именем и пересоберите сайт (npm run build).
