# Li Auto · Aster Li — сайт дилера в Самарканде

Премиальный лендинг официального дилера Li Auto (Aster Li, Самарканд) на русском и узбекском:
главная, 5 страниц моделей, политика конфиденциальности, форма заявки и бронирования с отправкой в CRM Oktell.

**Стек:** статический HTML/CSS/JS, собирается скриптом на Node.js **без зависимостей** (никакого `npm install`).
На сервере — только один PHP-файл для приёма заявок (`send.php`).

| | |
|---|---|
| Сборка | Node.js 18+ (`.nvmrc` → 22) |
| Хостинг | любой с PHP 8.2.35+ / 8.3.36+ / 8.4.27+ (Apache — `.htaccess` готов; nginx — `deploy/nginx.conf`) |
| Языки | RU (`/`), UZ (`/uz/`) |
| CRM | Oktell — `POST https://oktell.aster.uz:8443/aster/website-lead` |

---

## Быстрый старт

```bash
npm run dev        # собрать, открыть http://localhost:3000, пересобирать и обновлять браузер при каждом сохранении
npm run build      # собрать готовый сайт в dist/ — его содержимое загружается на хостинг
npm run serve:php  # проверить настоящую отправку формы локально (нужен PHP): http://localhost:8000
```

Работаем **только в `src/`**. Папки `dist/` и `deploy/nginx.conf` создаются сборкой — руками не правятся.

## Структура

```
liauto-site/
├── README.md                ← вы здесь
├── package.json             ← команды npm run dev / build / serve:php
├── docs/                    ← документация (см. ниже)
│
├── src/                     ← ВСЁ, ЧТО РЕДАКТИРУЕТСЯ
│   ├── content/             ← данные сайта (JSON) — тексты, модели, настройки
│   │   ├── config.json      ← телефон, соцсети, салон, CRM, аналитика, порядок моделей
│   │   ├── models/          ← по файлу на модель: тексты RU/UZ, характеристики, SEO, фото
│   │   └── i18n/            ← ru.json, uz.json — общие тексты интерфейса, FAQ, политика
│   ├── templates/
│   │   ├── pages/           ← home.html, model.html, privacy.html — разметка страниц
│   │   └── partials/        ← общие блоки: шапка, подвал, форма, окно бронирования, карточка модели…
│   ├── assets/
│   │   ├── css/style.css    ← весь дизайн (цвета и размеры — переменные в :root)
│   │   ├── js/main.js       ← меню, формы, бронирование, галерея, карта, аналитика
│   │   ├── img/             ← фото: home/ и models/<id>/ (card, hero, section-N, gallery-N)
│   │   └── fonts/           ← Manrope (локально)
│   ├── price/               ← PDF прайс-листов (кнопка «Скачать прайс-лист»)
│   ├── php/                 ← send.php (приём заявок → CRM), config.php (Telegram/e-mail, лимиты), .user.ini
│   └── server/              ← шаблоны .htaccess и nginx.conf (CSP подставляется при сборке)
│
├── scripts/                 ← СБОРКА (Node.js, без зависимостей)
│   ├── build.js             ← точка входа: собирает все страницы
│   ├── dev.js               ← локальный сервер + автообновление
│   └── lib/                 ← модули: шаблонизатор, картинки, SEO, CSP, соцсети, файлы сервера
│
├── build.js                 ← совместимость: «node build.js» = npm run build
├── dist/                    ← ГОТОВЫЙ САЙТ (генерируется) → на хостинг
└── deploy/nginx.conf        ← настройки для nginx (генерируется, если хостинг не Apache)
```
